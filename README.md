1. Опис проєкту
GiftCraft — це вебзастосунок для генерації ідей подарунків відповідно до отримувача, події та доступного бюджету.

Мета проєкту — допомогти користувачам швидко знайти цікаву ідею подарунка для близьких, друзів, колег та інших людей. Застосунок має простий інтерфейс українською мовою, адаптивний дизайн і можливість змінювати оформлення сторінки.

2. Основні можливості
Генератор подарунків: формування рекомендацій залежно від отримувача та події.
Вибір отримувача: чоловік, жінка, дитина, друг або подруга, колега, батьки, брат, сестра чи кохана людина.
Вибір події: день народження, Новий рік, річниця, весілля, випускний або подарунок без особливого приводу.
Налаштування бюджету: введення власної суми в гривнях.
Швидкий вибір бюджету: кнопки для сум 300, 1000 та 3000 грн.
Рекомендації відповідно до бюджету: додаткові поради залежно від суми, яку користувач планує витратити.
Три теми оформлення: стандартна градієнтна, темна та пастельна.
Збереження теми: вибране оформлення зберігається у браузері за допомогою localStorage.
Копіювання результату: можливість скопіювати сформовану ідею подарунка до буфера обміну.
Інформаційні секції: рекомендації щодо місць придбання подарунків та розділ FAQ.
Адаптивний інтерфейс: підтримка різних розмірів екрана за допомогою CSS media queries.
Перевірка введених даних: перевірка отримувача, події та коректності бюджету.
3. Використані технології
HTML5 — структура вебсторінки та форма введення даних.
CSS3 — стилізація елементів, адаптивна верстка, анімаційні переходи та теми оформлення.
JavaScript — обробка форми, генерація ідей, перевірка введених даних, перемикання тем і копіювання результату.
Web Storage API (localStorage) — збереження вибраної теми та можливість завантаження збережених користувацьких ідей.
Clipboard API — копіювання результату до буфера обміну.
Проєкт реалізовано без обов'язкових сторонніх JavaScript-бібліотек або фреймворків.

5. Основні компоненти та модулі
5.1. Головна секція
Презентує призначення застосунку та містить посилання для переходу до конструктора подарунків.

5.2. Конструктор подарунків
Містить форму з трьома основними параметрами:

отримувач;
подія;
бюджет.
Після заповнення форми користувач отримує картку з обраними параметрами та рекомендацією подарунка.

5.3. Генератор ідей
Функція getIdea(recipient, event, budget) вибирає відповідну рекомендацію зі словника ідей та доповнює її порадою відповідно до бюджету.

Якщо для конкретної комбінації немає готової рекомендації, використовується загальний текст.

5.4. Перемикач тем
Дозволяє вибирати між стандартною, темною та пастельною темами. Вибрана тема зберігається в localStorage і відновлюється під час наступного відкриття сторінки.

5.5. Кнопки швидкого бюджету
Функція setBudget(amount) автоматично встановлює одну з попередньо визначених сум у поле бюджету.

5.6. Картка результату
Відображає емодзі, отримувача, подію, бюджет та сформовану ідею подарунка.

5.7. Копіювання ідеї
Кнопка копіювання використовує Clipboard API для перенесення інформації про подарунок до буфера обміну.

5.8. Інформаційні секції
Секція «Де купити» містить загальні рекомендації щодо пошуку подарунків, а FAQ надає відповіді на поширені запитання.

6. Системні вимоги
Для використання вебзастосунку потрібні:

сучасний веббраузер із підтримкою HTML5, CSS3 та JavaScript;
підтримка localStorage;
підтримка Clipboard API для копіювання результату;
доступ до файлів стилів, які використовуються застосунком.
Для локального запуску не потрібні Node.js, npm, база даних або окремий сервер застосунку.

Для копіювання результату через Clipboard API браузер може вимагати безпечний контекст, наприклад HTTPS або локальне середовище localhost.
